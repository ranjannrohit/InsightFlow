Is my data private and secure? +
Yes! InsightFlow performs analytics, SQL execution, and chart rendering 100% inside your browser session. Your raw data is never saved or sold.
What file formats are supported? +
InsightFlow supports CSV files (.csv), Excel workbooks (.xlsx, .xls), and JSON datasets (.json).
How does the AI Analyst work? +
Our autonomous agentic backend combines Groq / Gemini LLMs with Python pandas dataframes to answer questions, execute SQL queries, and highlight key trends instantly.

Yes! You can generate formatted executive reports with one click and export them as PDF or HTML files.
